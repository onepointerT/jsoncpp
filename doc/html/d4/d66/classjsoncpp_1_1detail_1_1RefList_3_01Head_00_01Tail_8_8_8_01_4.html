Detailed Description

template<typename Head, typename... Tail>
class jsoncpp::detail::RefList< Head, Tail... >

A not-so-cute reference list with bivariate and varible template types stored.

Even a benefit in storage capacity with many elements. Less storage-expensive than AnyMap

Template Parameters
HeadThe first template parameter type
Tail...All other template parameter types
Note
The recursive inheritance stops, when sizeof...(Tail) == 0 with RefList<>.
